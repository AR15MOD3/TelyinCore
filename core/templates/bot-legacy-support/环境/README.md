# 环境 · 共用运行说明

> 这里描述 Bot 与框架交互的基本机制，不描述角色的全部世界。

## 保留在这里

这台机器.md 可以说明消息、工具结果与自身推测的区别，以及工具执行以真实回执为准等共用机制。
内容应对本 Bot 的各个入口都成立；部署路径、服务状态与工具能力以当前配置和实际查询为准。

## 不放在这里

- QQ 平台的消息格式、接收对象与发送能力：跟随 QQ 插件。
- 本机控制台的专属通道环境：跟随宿主入口。
- 图书馆、房间、设备偏好等角色设定：放在人格或知识层；核心与扩展资料按各自职责维护。
- 某次聊天、临时故障或测试数据：不是长期运行机制。

## 修改与验证

保持共用说明短而稳定，避免把同一条规则同时写在这里、人设和多个场景里。
README 是维护说明；实际装订文件由 Core 段序与当前通道接线决定，不按目录中 Markdown 文件的数量自动加载。
先填写与当前部署一致的说明，不复制已有 Bot 的私有配置。
