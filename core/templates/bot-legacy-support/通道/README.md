# 通道 · 新版场景映射

> 平台告诉系统“消息从哪里来”；Bot 场景描述“这个角色如何理解当前交流”。两者不混写。

## 当前布局

场景.json 按入口选择场景与表达文件；场景/ 和 表达/ 是 Bot 自己维护的内容。
console、internal、mixed、unknown 属于宿主入口；qq 的 provider 必须与实际注册的 QQ 插件一致。
来源未知或插件归属不匹配时走 unknown，不靠消息正文猜平台、熟人身份或投递目标。

旧的 QQ.md、控制台.md、独处.md 等文件保留兼容与回滚用途；新版映射以场景.json 的实际引用为准，不把两套正文一起叠加。

## 内容归属

- **宿主**：本机控制台、内部唤醒、多来源混合与未知来源的环境声明。
- **插件**：QQ 等外部平台的真实能力、消息类型与平台约束，跟随插件安装与注册。
- **Bot**：当面或远程的角色场景、措辞与表达偏好；不能伪造已发生的动作、身份认证或工具权限。

QQ 的平台环境声明在插件侧维护；不要把它复制进 persona/ 或当前目录来形成第二份正本。
角色世界里的联络设备可以属于世界设定，但它不等于真实 QQ 接口，也不是认证凭证。

## 编辑约定

先判断改的是平台事实、角色场景还是表达习惯。平台事实交给宿主或插件，后两项才属于这里。
新版映射按启动快照加载，改 JSON 或场景内容后应按现有发布流程验证并重启对应 Bot；不要重启其他 Bot。
本 README 只用于维护说明，不应出现在场景.json 的 files 引用里。
