# 内置插件

这里保存随项目提供的插件源文件；`infinity/` 专门放 `core-infinity` 类插件。
QQ 连接源码在 `infinity/core-infinity-qq/`，与 `extensions/` 中实际安装的副本分开。
卸载只删除安装副本；源文件仍留在这里，所以插件页会继续显示停用的灰卡。
卡片上的「安装」将源文件复制到 `extensions/`，安装后由用户决定是否启用。

## 已退役组件

视觉叠加已从 Core 内置源和安装副本中移除，不再提供重装入口。
其源码保留在 Core 外的磁盘归档；这不改变 QQ 连接和通用图片收发能力。
