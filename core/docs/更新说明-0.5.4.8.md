# 0.5.4.8

本次更新统一页面布局，改进侧边栏、搜索和内容浏览。现有 Bot 数据、模型配置和插件启停状态保持不变。

- 修复宽屏下知识库正文仍限制为窄列的问题，插件说明和设置内容同步使用可用宽度；知识库和画像根据侧边栏占用后的实际空间切换布局。
- 页面标题、筛选和底部操作按统一的间距与样式排列。知识库、画像及插件页的列表和详情可独立滚动；内容较长时仍可看到主要操作。
- 控制台统一名称和标题格式，对话记录与输入框对齐。顶栏保留两行布局，显示当前 Bot、版本及检查更新入口；点击模型名称可打开模型配置。
- 侧边栏搜索直接在栏内展开，支持 Ctrl+K / Cmd+K、方向键和 Enter。点击页面或搜索结果下方的空白处可收起搜索。
- 修复拖动侧边栏时搜索、分组标题和高级设置被挤成多行的问题。窄栏及时切换为图标布局，文字逐渐淡出，松手后平滑收拢；选中项使用浅色底和细边框。
- 画像按平台分组，控制台组置顶；已确认关联控制台的账号在各自平台组内置顶，其他平台接入后自动分组。
- 画像简化为平台与账号显示，同一 QQ 账号的群内相遇记录集中展示。无内容的人物概述不再显示占位说明；账号关联可按需展开。
- 经历按实际日期分组，未注明日期的记录单独列出，修复重复“更早”分组。记录来源集中查看，知识库和经历正文背景跟随主题。
- 精简加载、空状态及记录来源文案。工具简介最多显示两行，完整说明可通过“显示全部”查看；QQ 首次部署说明按需展开。
- 插件市场、总览和 QQ 配置页统一标题、详情及底部信息布局。继续支持 GitHub 插件历史版本安装；QQ 连接 0.9.2 仍随 Core 更新。

## 更新

Windows 已安装 0.5.4.7 可在 Core 顶栏检查更新，或下载对应的 0.5.4.7 → 0.5.4.8 更新包。
本次发行同时保留 0.5.4、0.5.4.1、0.5.4.2、0.5.4.3、0.5.4.5、0.5.4.6 的升级包。
手动安装前请正常退出该部署内的所有 Bot。更新包不会覆盖 Bot 数据、模型文件和用户配置。
