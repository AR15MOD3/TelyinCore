# 你的插件（这一份是模板）

> 这是一份**能直接改的骨架**。改完记得做三件（见 [`../../docs/plugins.md`](../../docs/plugins.md)）：
> ① 给仓库打话题 **`core-infinity-plugin`**；② 打一个 tag（比如 `v0.1.0`）；
> ③ 确认 `package.json` 的 `keywords` 里有 **`core-infinity`**。

## 它是什么

一句话：**（写清这个插件干什么）**。

 这一句会出现在那边的市场卡片上（取自 `package.json` 的 `description`），
所以**先说"它解决什么"，再说"它怎么做到"**。

## 它给模型什么工具

| 工具名 | 干什么 |
|---|---|
| `my_ask` | 问一句，它就答一句（ 换成你自己的） |

## 它用 `ctx` 里的什么

| 用到的 | 干什么 |
|---|---|
| `log` | 记一行 |
| `push_event` | 报一件事（进事件库） |
| `model_facts` | 读当面的模型名 ／ 窗口 |

 **每一样都先 `ctx.get(...)` 看它在不在**——没给的就是没给，而你的插件照跑。

## 装它的人会看到什么

```
① 在市场里看到这个仓库（ 因为你打了那格话题）；
② 点"装" ⇒ 下这一份归档 ⇒ 查 keywords ⇒ 装进 extensions/；
③ 装好**不会自动开**；开了之后才会 import 这一份、叫 `create(ctx)`；
④ 开了之后，上面那个工具就进了模型的工具表 —— 它真的调得到。
```
