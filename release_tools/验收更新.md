# 平台验收更新

发行标签 `linux-acceptance-beta.0.1.1` 对应本机开发基线的验收包。普通安装使用正式发行线。准备验收的安装可在部署根目录的 `runtime/release-channel.json` 写入 `{"channel":"acceptance"}` 后正常重启，并在 Core 顶栏完成更新。恢复正式线时删除该选择文件并重启。变更发行线只影响检查范围，安装仍会校验本地程序与发行基线。

Linux beta.0.1.3 提供一键更新和统一下载源。验收附件分别对应已接入新版更新入口的本机 beta.0.1.0 和原验收版 beta.0.1.1。正式版继续使用正式发行线。

## Windows

Windows beta.0.5.4.3 的发行登记指定验收通道。可直接使用完整包，或从 beta.0.5.4.1、beta.0.5.4.2 安装对应的离线更新包。顶栏显示的 beta.0.5.4.4 来自 GitHub 验收发行标签。安装完成后可在版本面板查看上次安装来源。
