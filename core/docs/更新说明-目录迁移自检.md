# Windows beta.0.5.5 与 Linux beta.0.2.1

移动整个部署后，从新目录打开启动入口。Windows 会核对当前 Bot 的账号预留、收件记录、语音模型、Python 入口和已识别的计划任务。Linux 会在加载档案前核对原目录归属，修复档案标记、账号预留、收件记录、模型配置、虚拟环境命令及原部署的应用菜单入口。

迁移保留原文件备份。旧目录还有可启动的 Core、账号归属有冲突或模型不完整时，启动器会给出提示。重复启动会复用已通过的检查。Windows 可以用 Core 环境运行 `windows_relocation.py --bot <Bot名> --rescan` 再次核查。

Windows 新发行包使用三段数字版本号。已安装 beta.0.5.4.9 或 beta.0.5.4.10 的部署可直接更新到 beta.0.5.5。Linux 当前发行号为 beta.0.2.1。
